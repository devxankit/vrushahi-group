# PART A — RAW EXTRACTION

## A1. Tech stack of the legacy site (as found)

- Static HTML, no build system, no CMS. Template family: **OS-Templates** ("layout/styles/framework.css" + "layout.css").
- jQuery-based nav (`jquery.mobilemenu.js`), back-to-top (`jquery.backtotop.js`).
- Homepage hero is a **DHTML slideshow embedded via `<iframe src="slideshow.html">`** using a very old cross-browser `slideshow.js` (VBScript/IE filter transitions like `DXImageTransform.Microsoft.Wheel`) — this is dead/legacy tech and must not be ported as-is.
- Two **PHP form handlers** (`career.php`, `contact-us.php`) exist with real server-side validation, CSRF token, math captcha (image generated by `form/img.php`), and email delivery — but they are **not linked from the navigation anywhere**. The nav instead points to `career.html` / `contact-us.html`, which are unfinished template placeholders. (See A6 and A8 — Known Issues.)
- No routing framework — every page is a full physical `.html` file that duplicates the entire header/nav/footer markup (~140 lines repeated 29 times).
- 29 distinct top-level pages + a `pages/` and `layout/` folder of unused template boilerplate (basic-grid, sidebar-left/right, gallery — not linked from the live site, safe to ignore).

## B12. Modern, animated design direction

The legacy site is flat, static, no motion at all — the rebuild should feel current. Guidance for the visual/motion design:

**Visual language**
- Generous whitespace, large confident type for headings (a strong display font paired with a clean body sans — e.g. a modern grotesk/serif display + Inter/Manrope body), clear visual hierarchy per section.
- Soft depth: subtle shadows, large soft-rounded corners (`rounded-2xl`/`rounded-3xl`) on cards, occasional gradient or duotone overlays on hero/section-break imagery (using the brand red/amber as the gradient accent) instead of the old flat photo-with-caption tiles.
- A consistent card system for the business-unit grid: image (placeholder for now) + eyebrow/cluster label + title + 1-line summary + hover state.
- Dark-friendly footer treatment (the legacy dark photographic footer overlay is a nice cue to keep, modernized with a solid deep charcoal/gradient instead of a stretched JPG).

**Motion / interaction (this is the "animated modern" part)**
- Use **Framer Motion** as the primary animation library for React (page-level and component-level), optionally layering in **GSAP + ScrollTrigger** if you want more elaborate scroll-choreography on the homepage.
- **Page transitions:** animate route changes (fade/slide) via Framer Motion's `AnimatePresence` so navigating between business-unit pages feels continuous, not a hard reload.
- **Scroll-reveal:** sections (hero copy, "Our Experience" block, business-unit grid cards, About page blocks) should fade/slide into view on scroll (`whileInView`), staggered for grids so cards animate in sequence rather than all at once.
- **Hero:** animate headline/tagline in on load (staggered word or line reveal), animated scroll-cue affordance, and a subtle parallax or slow Ken-Burns-style motion on the (placeholder) hero image/video instead of the old iframe slideshow.
- **Mega-menu & mobile drawer:** animated open/close (height/opacity spring transitions), animated active-state underline/highlight on nav items, smooth accordion expand for the multi-level Group submenu on mobile.
- **Micro-interactions:** buttons/links get a hover scale or underline-draw effect; business-unit cards lift/scale slightly and reveal a "View division →" affordance on hover; form inputs get animated focus rings/labels (floating label pattern) and inline animated validation/success states; the Career/Contact submit buttons show an animated loading + success/error transition instead of a static banner swap.
- **Back-to-top button:** animate in/out based on scroll position rather than a hard show/hide.
- Respect `prefers-reduced-motion` — every animation above should have a reduced/instant fallback for accessibility, and none of it should block Lighthouse performance targets (B7) — prefer CSS transforms/opacity (GPU-friendly) over layout-triggering animations, and lazy-mount heavier scroll effects.
